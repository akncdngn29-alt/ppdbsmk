Konvensi Primary Key

Primary Key Eksplisit: id_<nama_tabel>

Semua tabel memiliki PK berformat eksplisit: id_user, id_admin, id_jurusan, id_gelombang, id_pendaftar, id_berkas, id_pembayaran, id_terima, id_jadwal, id_ruang, id_penempatan, id_nilai, id_log, id_voucher, id_prestasi. FK mereferensikan langsung nama PK tabel asal (Normalisasi 3NF).

🔒 Konvensi Primary Key (3NF)

Setiap tabel memiliki PK eksplisit berformat id_<nama_tabel>. FK selalu mereferensikan nama PK tabel asal. Tidak ada composite key — semua PK bersifat single auto-increment BIGINT.

🛡️ Keamanan File Upload

Dokumen disimpan di storage/app/private/berkas/. Akses hanya lewat controller terautentikasi (Secure Stream). Tidak bisa dibuka langsung via URL publik.

⚡ Anti Race Condition

Nomor pendaftaran REG-2026-XXXXX dibuat melalui tabel pendaftaran_sequences dengan lockForUpdate() (Pessimistic Locking) agar tidak ada nomor duplikat meski ribuan siswa daftar bersamaan.
